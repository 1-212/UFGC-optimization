# GC Optimization Project

## Project Introduction

GC Optimization is a Python application for optimizing and analyzing Gas Chromatography (GC) related data. The project provides a comprehensive set of tools including data parsing, optimization algorithms, and visualization analysis, designed to help researchers more efficiently analyze and process GC data.

## Project Structure

```
gc_optimization/
├── checkpoints/        # Experiment checkpoints and logs
├── visualizations/     # Visualization results

gc_optimization_app/
├── core/               # Core functionality modules
│   ├── constraint.py   # Constraint handling
│   ├── optimizer.py    # Optimization algorithm implementation
│   └── signal_process.py # Signal processing
├── data/               # Data processing modules
│   ├── asc_parser.py   # ASC file parsing
│   └── manager.py      # Data management
├── tests/              # Test files
├── ui/                 # User interface
│   ├── main_window.py  # Main window
│   └── panels.py       # Interface panels
├── utils/              # Utility functions
│   ├── file_handler.py # File handling
│   └── logger.py       # Logging
├── visualization/      # Visualization module
│   └── plotter.py      # Plotting functionality
├── config.py           # Configuration file
├── main.py             # Main entry point
└── requirements.txt    # Dependencies
```

## Installation

### 1. Clone the project

```bash
git clone [repository URL]
cd GC
```

### 2. Install dependencies

```bash
pip install -r gc_optimization_app/requirements.txt
```

## Usage

### Command line execution

```bash
python gc_optimization_app/main.py
```

### Features

1. **Data parsing**: Supports parsing of ASC format GC data files
2. **Parameter optimization**: Provides Bayesian optimization algorithm for optimizing GC analysis parameters
3. **Visualization analysis**: Generates convergence curves, time distribution, parameter sensitivity analysis, etc.
4. **User interface**: Provides a graphical interface for easy user operation and analysis

## Core Features

- **Signal processing**: Preprocesses and analyzes GC signals
- **Constrained optimization**: Performs parameter optimization while satisfying constraints
- **Data management**: Efficiently manages and processes GC data
- **Visualization**: Generates various types of visualization charts to aid analysis and decision-making

## Experimental Results

Visualization results generated by the project are stored in the `gc_optimization/visualizations/` directory, including:

- Convergence curves: Show the convergence of the optimization process
- Time distribution analysis: Analyze time consumption during optimization
- Parameter sensitivity analysis: Evaluate the impact of different parameters on optimization results
- High-dimensional parameter space analysis: Visualize the optimization process in high-dimensional parameter space
